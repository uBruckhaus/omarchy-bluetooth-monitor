# Bluetooth Monitor (Omarchy plugin)

**Every wireless device at a glance: battery and connection, in one picture.**

Mice, keyboards, trackpads, earphones and game controllers: Bluetooth Monitor shows
how full each battery is and how each device reaches your PC, whether over Bluetooth
or through a Logitech USB dongle (Unifying, Bolt, Nano, Lightspeed). The
**connection map** draws it as a tree: this PC, every dongle and the Bluetooth adapter
(solid line: plugged in), and the devices on each (dotted line: radio), with their
battery. You can see right away which dongle a device needs and which dongle has free
slots.

The bar icon stays quiet until it matters: green while all batteries are fine,
**orange** when one runs low, **red** when one is critical, and it turns into the
device that needs charging (keyboard, trackpad, earphones, controller; mouse on a tie).

Logitech devices get more: pointer speed (DPI), SmartShift and scroll-wheel mode,
natural and high-resolution scrolling and the Fn-key swap, straight over Logitech's
HID++ protocol, no Solaar or Logi Options needed.

Per Logitech device, when the hardware supports it:

- battery (percent, charging)
- pointer speed (DPI)
- scroll wheel mode: SmartShift / ratchet / free spin, SmartShift sensitivity
- natural and high-resolution scrolling
- Fn-key swap

Settings you change are remembered in `~/.config/omarchy/bluetooth-monitor/settings.json`
and written again when a device reconnects.

## Languages and settings

The gear in the panel opens the settings page (back with the button, Backspace or Esc):

- **Language**: system language (default) or English, Deutsch, Français, Español,
  Italiano, Português, Nederlands, Polski
- **Low / critical battery warning**: when the bar icon turns orange / red
  (25 % and 10 % by default)
- **Show switched-off devices**
- **Other Bluetooth devices**: trackpads, earphones, controllers from UPower
- **Receiver access**: whether the udev rule is in place, with the Allow button

Choices are stored in the widget's own entry in `~/.config/omarchy/shell.json`.
`I18n.js` is generated by `~/Projects/omarchy-plugin-i18n/build.py` from
`strings/bluetooth_monitor.py`.

## How it works

Non-Logitech peripherals come from UPower (`upower --dump`, battery only); a
`upower --monitor` child process (tied to the helper's lifetime) triggers a rescan when a
battery changes or a device connects. Logitech devices are shown once (HID++ wins).

`scripts/bluetooth-monitor.py` (Python stdlib only) talks Logitech's HID++ protocol
straight over `/dev/hidraw`. No Solaar, no daemon besides the helper the bar widget runs.

Access to `/dev/hidraw` is root-only by default. The panel's **Allow access** button
runs `scripts/allow-access.sh` through `pkexec`; it installs
`/etc/udev/rules.d/42-omarchy-logitech-devices.rules`, which gives the logged-in user
(`uaccess`) access to Logitech hidraw nodes, the same scope as Solaar's rule. Remove the
file to revoke it.
